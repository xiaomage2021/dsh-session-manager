# dsh-session-manager —— DSH 全局会话管理插件

在左侧导航栏的「上下文洞察」下方增加一个**「会话管理」**入口，点开后在中央面板以仪表盘与卡片网格布局，集中管理与概览**所有工作区**的会话对话。

---

## 📸 界面布局与对齐（参考上下文洞察与仪表盘卡片风格）

- **顶部统计仪表盘（可点击）**：
  - **会话总数**：聚合全部工作区下的历史会话与活跃会话数量；点击切换为「全部状态」总览
  - **运行中会话**：绿色高亮实时统计当前正在后台工作/执行的会话；点击只看运行中
  - **已归档会话**：标记处于安全隔离与清理归档状态的会话；点击进入归档视图
  - **工作区数量**：当前接入的物理工作区总数；点击回到「在用 + 全部工作区」总览
- **筛选工具栏**：
  - **即时搜索框**：支持按会话标题、会话 UUID 或工作目录路径过滤
  - **工作区下拉/胶囊标签**：支持单选指定工作区，或查看“全部工作区”与“未归组”会话
  - **状态筛选**：支持快速切换“在用会话”、“运行中会话”、“已归档会话”或“全部状态”
  - **刷新按钮**：即时重新同步底层状态
  - **全部彻底删除**：仅在「已归档」视图下出现，一键清空全部已归档会话（红色危险按钮 + 二次确认）
- **批量操作条**：
  - 勾选任意卡片后，激活批量操作条：支持「批量删除（归档）」、「批量转移到指定工作区」、「全选/取消」；在归档视图下自动切换为「批量彻底删除」
- **会话卡片网格（分组陈列）**：
  - **工作区胶囊标签**：卡片顶部醒目标注工作区名称（如 `[小马工作室]`），点击直接单选筛选该工作区
  - **状态徽章**：运行中（绿色边框+徽章）、已置顶（橙色徽章）、已归档（灰色半透明遮罩）
  - **卡片动作**：
    - `打开`：点击卡片标题或打开按钮直接切换进入该会话
    - `重命名`：快速修改会话显示标题
    - `置顶 / 取消置顶`：调整会话优先展示顺序
    - `转移`：弹窗选择目标工作区，自动迁移会话首帧头部 cwd、会话目录物理归属与注册表账本
    - `删除 / 恢复`：在用状态下点击删除执行软归档；在已归档视图下可一键「恢复」
    - `彻底删除`：已归档会话卡片上专属展示红色的「彻底删除」按钮，支持单个彻底删除与批量彻底删除（文件安全移入回收站缓冲并在系统中彻底抹除，杜绝硬删除风险）
    - **运行中保护**：真正处于运行状态的会话会被跳过并在提示中说明，不会阻断其余会话的删除（判据为宿主的 `agent.status === 'running'`，而非「会话已加载」）
- **批量操作强化**：
  - 在用会话支持批量移入归档或批量转移；已归档视图下自动切换为**「批量彻底删除」**，一键批量清空失效会话。
- **左侧工作区树右键菜单无缝扩展**：
  - 在左侧会话项的三点菜单 / 右键上下文菜单中的「归档会话」正下方，无缝增设两个操作项：
    - 📁 **移动会话**（`order: 700`）：弹窗列出其他工作区，确认后一键迁移；
    - 🗑️ **删除会话**（`order: 800`）：危险操作红色高亮，带二次确认弹窗，确认后将该会话安全移出工作区并归档。

## 🛠️ 核心架构与实现机制

1. **入口注册（Cordis + Slots 规范）**：
   - 侧边栏按钮：向 `sidebar.panellist` 注册，`order: 21`（紧跟上下文洞察 `order: 20` 之后）
   - 主视图面板：向 root scope 的 `main` keyed 槽注册（key 与侧栏 id 严格对齐）
2. **数据接入层（双重兼容模式）**：
   - 会话数据：同时兼容订阅 `sessions.list.getSnapshot()` 与 `sessions.manager.getListSnapshot()`，健壮提取 `{ id, displayTitle, title, cwd, running, blank, updatedAt }`，永不抛错
   - 工作区数据：订阅 `workspaces.list.getSnapshot()`，动态匹配工作区路径与标题
3. **跨工作区转移机制**：
   - 由于 DSH 底层会话归属严格由首帧 zstd 解压后头部 JSON 中的 `cwd` 与目录层级（`sessions/<projectKey>/`）决定，插件宿主半身（`lib/index.js`）提供了原子级别的首帧改写与目录迁移功能：
     - **事前校验**：运行中的会话拒绝操作，避免损坏日志流；
     - **完整备份**：操作前自动将原始会话目录与 `workspace.json` 备份到 `~/.dsh/session-manager-backups/`；
     - **首帧改写**：精确定位 zstd 第一个 magic 帧边界，仅改写首帧的 `cwd`，后续所有事件帧 100% 保持二进制原样不变；
     - **无损检验**：改写完成后执行全帧逐帧校验，若有任何异常立即无条件回滚；
     - **重启生效**：因 DSH 在启动时将工作区与会话绑定索引加载入内存，会话转移后提示用户重启客户端以刷新工作区归属。
